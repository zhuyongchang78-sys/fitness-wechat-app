# 健身辅助微信小程序

面向 14–55 岁健身新手的微信小程序项目。第一阶段交付手机尺寸的可点击网页原型，后续实现微信小程序与云开发数据存储。

## 年龄分层

- 14–17 岁：采用青少年安全模板，强调动作学习、全面体能和适龄训练；不直接套用成人热量缺口、热量盈余或极限负重规则，并加入监护人知情提示。
- 18–39 岁：采用常规新手增肌、减脂和体型保持模板，根据训练经验、目标和器械条件匹配计划。
- 40–55 岁：强化健康风险筛查、热身、恢复和渐进负荷；存在慢性病、伤病或明显不适时停止自动生成计划并提示咨询专业人员。
