# 可点击网页原型

直接打开 `index.html` 即可体验。建议使用手机浏览器，或在桌面浏览器中以约 390 × 844 的手机视口预览。

当前已实现：

- 首页目标选择与基础资料填写
- Mifflin–St Jeor 代谢和目标热量估算
- 14–17、18–39、40–55 岁分层提示与健康风险拦截
- 健身房、居家、今日计划切换
- 训练重量、次数、完成状态与容量计算
- 动作部位、器械和关键词筛选
- 动作步骤详情、饮食计划与个人数据界面
- 动作图片与名称分区展示，详情页优先显示 GIF，步骤按需展开
- BMI、围度体脂率、14–18 岁/19–55 岁分公式基础代谢和体重管理工具
- 周训练容量、有效组数、上周对比、每日柱状图和下周渐进目标

界面已重做为白底、薄荷绿和轻阴影卡片风格，导航为“首页、计划、动作、饮食、我的”。人物横幅与健康饮食横幅由图像生成工具为本项目原创生成。

动作库现已接入 30 个真实新手动作样本，包含中文步骤、缩略图和 GIF 动画。媒体来自用户提供的数据包，版权属于 Gym Visual，仅用于本地内部原型验证并保留署名；对应媒体目录已加入 Git 忽略规则，不能直接随公开版本发布。
